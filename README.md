# TNE Plumbing — website redesign

A responsive, conversion-focused redesign for Thong Nian Engineering / TNE Plumbing.

## Open locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Contents

- `index.html` — semantic page structure and conversion copy
- Nine service directories — dedicated static pages at the original service URL paths
- `SERVICE-CONTENT.md` — verified source pages and content decisions
- `styles.css` — responsive visual system
- `scripts/main.js` — accessible mobile navigation and privacy-conscious WhatsApp quote flow
- `assets/` — original logo and selected job imagery from the current client website
- `_headers` and `SECURITY.md` — deployment security guidance
- `robots.txt` and `sitemap.xml` — crawl directives for the production domain

## Conversion improvements included

- Prominent 24/7 phone and WhatsApp calls to action
- Short, scan-friendly service and benefit content
- A focused, low-friction quote flow
- Service-specific messaging for commercial/F&B customers
- Trust and process content close to conversion points
- Mobile-first navigation, strong contrast and keyboard accessibility
- Search-friendly title, description, canonical URL, social sharing metadata and local-business structured data

## Pre-launch checklist

1. Confirm service descriptions and contact details with the client.
2. Test every phone and WhatsApp link on iOS and Android.
3. Deploy over HTTPS and apply the security headers for the chosen hosting provider.
4. Add real customer review links / evidence and a privacy policy before collecting form data server-side.
